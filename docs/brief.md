# Бриф проекта

Сайт-мануал для асессоров Data Light, которые собирают на YouTube ссылки на видео с определённым движением для датасета Kandinsky — три параллельные заявки: повседневность (1075), танцы (1076), спорт (1077). Задания (включая экзамен) асессоры выполняют в личном кабинете на платформе Tagme, доступ к которой выдаёт руководитель группы Data Light.

Уникальность сайта — он объединяет в одном понятном источнике то, что сейчас разбросано по PDF и переписке: официальную инструкцию заказчика, критерии отбора видео, чек-лист по блочности, разбор примеров и обратную связь заказчика по первым заданиям.

Для кого: асессоры проекта (Анна Щербакова — 1075, Виктория Котенко и Анастасия Сорока — 1076, Андрей Котенко — 1077) и куратор, который ведёт все три заявки.

На выходе — небольшой статический HTML-сайт на основе черновика `site/manual-1075-1077.html`, который будет опубликован на GitHub после согласования финальной структуры.
