## 9 подтверждённых пунктов (вопросы 16.09 → ответы заказчика)

Нумерация вопросов и ответов совпадает 1:1 (4 пункта «нужно уточнить» + 5 «прошу подтвердить» = 9 ответов).

1. **HD-разрешение через переключение качества.** Прямого ответа на нюанс «HD по умолчанию vs HD только при ручном переключении» нет — заказчик просто повторил общее правило (поле 1 = разрешение + блочность отдельно проверяются). Смысл раскрылся через таблицу ОС по 1075 (см. ниже, «Комментарий 1») — это де-факто и есть развёрнутый ответ. → **Блочность**
2. **Перекрытие ГО предметом/тренажёром** (не только текстом) — та же логика, что и с текстом: небольшое перекрытие допустимо. Будет добавлено в инструкцию заказчиком. → **Какие видео подходят/не подходят**
3. **Естественная медленность vs искусственное замедление** — можно выполнять в своём темпе, но кадр не должен быть искусственно ускорен/замедлен (видно по «рваным» движениям). → **Какие видео подходят/не подходят**
4. **Недоступность видео после отправки / региональные различия** — ошибку не ставят, но комментарий обязателен. → **Обзор проекта** (или примечание в «Какие видео подходят»)
5. **Идентичность по траектории, не по названию** — ориентир: видео с лучшим качеством, прошедшее блочность; остальные видео должны быть идентичны именно ему (поза, руки, ноги). → **Какие видео подходят/не подходят** + страницы заявок
6. **1075 не включает спорт/тренажёры**, даже если действие ежедневное и домашнее (пример из ОС: приседания на стул отклонены, хотя асессор возражал, что это бытовое действие). → **Заявка 1075**
7. **Мелкая моторика** — собирать только при полной, чётко видимой идентичности; иначе комплект не подходит, даже при совпадающем названии. → **Какие видео подходят/не подходят**
8. **Название движения ≠ поза/дисциплина.** Примеры: «фигурное катание» — не движение, «волчок» — движение; «поза кобры» — не движение, «поднятие корпуса из положения лёжа» — движение; «плие» — движение, «танец танго» — не движение. → **Блочность-страница не подходит, это критерии** → **Какие видео подходят/не подходят** + примеры на страницах заявок 1076
9. **Лучшее по качеству видео — строго в поле 1**, не просто где-то среди пяти ссылок. → **Какие видео подходят/не подходят**

## Ключевое разъяснение по блочности (из таблицы ОС по 1075, «Комментарий 1»)

Это резюме почти дословно повторяется десятки раз в таблице ОС как отсылка «смотрите комментарий 1» — стоит вынести на страницу «Блочность» отдельным блоком:

> В инструкции два разных пункта: один — про разрешение, второй (чек-лист) — про качество изображения. По чек-листу нужно анализировать САМОЕ ЛУЧШЕЕ видео: если на ГО нет блочности (расслоений/пикселей/шумов) — дальше анализируем весь кадр по чек-листу; если набралось 3 пункта «против» — видео не подходит по качеству. Остальные 4 видео так детально не проверяем — важно только, чтобы само действие было идентичным.

Вывод: «есть переключаемое HD-качество на YouTube» и «прошло по блочности» — это две независимые проверки, одно не гарантирует другого. Ассессоры в примерах регулярно путали одно с другим.

## Частые паттерны ошибок по заявке 1075 (из таблицы ОС, ~20 разобранных заданий)

- Спорт/упражнения/тренажёры не относятся к «повседневности», даже если выполняются дома каждый день (приседания на стул, отжимания от стены, ягодичный мостик, планка на боку, упражнение «бабочка», «кошка», «колечко» и т.д. — почти все отклонены по этой причине).
- Идентичность — это не только название и не только траектория, а вся поза целиком: положение рук, ног, поворот и наклон корпуса.
- Видео с лучшим качеством обязано быть именно в поле 1 (примеры: «Ягодичный мостик», «Езда на лошади» — лучшее видео стояло не в 1-м поле).
- Недоступность видео из-за VPN/региона — не ошибка, но нужен комментарий валидатора (примеры: «Игра на цимбалах», «Упражнение карзинка»).
- Мелочь, но важно: названия движений — без опечаток (пример: асессор написал «карзинка» вместо «корзинка»).
- Небольшое перекрытие тренажёром/предметом допустимо по той же логике, что и с текстом (пример: «Бег на беговой дорожке» — тренажёр немного перекрывает движение, это ок).
- Даже небольшое, малозаметное искусственное ускорение — повод отклонить видео целиком (пример: «Отжимание головой вниз», 5-е видео).
- Танцевальные элементы («плие») по-прежнему пытаются сдать в 1075 — отклоняется однозначно.

## Новое о процессе работы (в текущем мануале этого нет)

- Если 1–2 ссылки в задании не проходят — **дорабатывать задание нельзя**: оно целиком уходит в статус «Битое» на следующем этапе; отклонённое движение можно собрать заново отдельным новым заданием.
- Для 1076 и 1077 пулы одному разметчику открываются **по одному** (не сразу все) — иначе он не заметит смену категории и продолжит собирать по старой теме. Новый пул подключают и сообщают отдельно по окончании предыдущего.
- Для 1075 следующий пул открывается автоматически.
- Экзамен общий для всех трёх заявок, проходной балл — 85%. После экзамена заказчик сам распределяет по заявкам; асессор работает только на одной заявке.

Рекомендация: первые три пункта хорошо ложатся в «Обзор проекта» (как устроена работа/проверка), последний уже есть в разделе про экзамен.

## Официальные обновлённые инструкции по каждой заявке (16.09.2026)

Заказчик прислал три отдельных документа — по одному на заявку (`sources/Заявка_1075...pdf`, `..._1076...pdf`, `..._1077...pdf`). Важный вывод: раздел «Критерии сбора», чек-лист по блочности, корнер-кейс (человек сильно перекрыт предметом) и FAQ **дословно идентичны** во всех трёх документах. Это подтверждает правильность общих страниц «Какие видео подходят/не подходят» и «Блочность» — дублировать их по страницам заявок не нужно.

**Новое в официальных инструкциях (чего не было в черновике сайта):**
- Официальный FAQ-пункт: «Разрешение HD и качество — это одно и то же?» → Нет, это две отдельные проверки (разрешение отдельно, блочность по чек-листу отдельно). Введён термин **«эталонное видео»** — видео с лучшим качеством и разрешением, по которому сверяют движения на остальных видео; оно же идёт в поле 1.
- Официальный FAQ-пункт: «Будет ли ошибкой неверное написание движения или неверная формулировка?» → Да, оба случая — ошибка.
- Корнер-кейс с картинкой: пример, где человек сильно перекрыт предметом → видео не подходит (картинка хостится на tagme.sberdevices.ru, недоступна без логина — на сайте придётся either описать словами, либо запросить у пользователя скриншот).
- Уточнение по перекрытию: если человек **сильно** перекрыт предметами или наложениями — не берём (раньше в черновике был только акцент на «небольшое» перекрытие допустимо, порог «сильно» не был явно назван).
