# Структура сайта-мануала

Статус: исторический план, утверждённый 2026-09-16. Общая структура (6 страниц, разделение обзор/критерии/блочность/заявки) сохранилась, но детали ниже с тех пор менялись на практике (например: страница 2 называется «Правила отбора видео», а не «Какие видео подходят»; «Разбор общих примеров» был удалён как раздел; из таблицы заявок убрана оплата; источник видео на сайте называется «видеоисточник», без слова YouTube). Актуальное описание структуры и решений — в `CLAUDE.md`, этот файл оставлен для истории.

Навигация — справа, 6 страниц, без отдельной FAQ и без отдельной страницы «Частые ошибки» (ошибки размещаются на страницах конкретных заявок).

Важное правило: **на сайте нет персоналий**. Кто именно сейчас работает на какой заявке/пуле — не указывается нигде, мануал общий и не привязан к конкретным людям.

## 1. Обзор проекта
- Что за проект, единая механика сбора (одно и то же движение, комплект из 5 ссылок)
- Таблица различий заявок: тематика + объём + оплата + скорость (1075/1076/1077)
- Как попасть на проект: экзамен (85%), общий механизм распределения по заявкам и пулам — без имён
- Платформа Tagme: личный кабинет, доступ выдаёт руководитель группы Data Light
- Источник видео: только YouTube, не ИИ, длительность ≤30 мин
- Основные термины кратко (ГО, блочность) со ссылкой на страницу «Блочность»

## 2. Какие видео подходят / не подходят
- Формат задания: 5 ссылок + название движения, ссылка 1 — обязательно HD 1280×720
- Критерии отбора видео (таблица: длительность, склейки, различимость людей, вотермарки, повторы и т.д.)
- Разбор общих примеров (в т.ч. 4 видео-примера из `sources/`)
- Чек-лист перед отправкой задания

## 3. Блочность
- Термины ГО и блочность подробно
- Главное правило (блочность на ГО → видео не собираем)
- Чек-лист из 5 пунктов + правило подсчёта (3 из 5 «против» → не берём)
- Разобранный пример с вердиктом
- Материал из «Вопрос про ГО и блочность» + `image.png`

## 4–6. Заявка 1075 / 1076 / 1077 (единый шаблон)
Каждая страница:
- О заявке — тематика движений, что именно ищем
- Пулы — список видов танца/спорта (для 1076/1077); **список пришлёт пользователь отдельно**
- Особенности отбора именно для этой темы (например: 1075 — актуальное правило про ракурс; 1076/1077 — жанр ≠ название движения)
- Практика — разобранные примеры именно по этой теме, если есть
- Частые ошибки по этой заявке (источник — ОС заказчика, переписка)
- Как называется задание в системе (naming)
