# Заявки 1075–1077 (Kandinsky. Движения — сбор ссылок)

Сайт-мануал для асессоров Data Light по сбору ссылок на видео с определённым движением — для датасета Kandinsky. Три параллельные заявки: повседневность (1075), танцы (1076), спорт (1077). Задания и экзамен асессоры выполняют в личном кабинете на платформе Tagme.

Живой сайт: https://ekaterina-dl.github.io/1075-1077-manual/

Чтобы посмотреть сайт локально, открой `site/overview.html` в браузере (или через локальный сервер — плеер с видеопримером на странице «Блочность» требует http, не file://). Исходники от заказчика — в `sources/` (не для публикации, см. `CLAUDE.md`), история и планы проекта — в `docs/`.
